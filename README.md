# Checkpoint — demo pública

https://balhoo.github.io/Checkpoint-Demo/

Biblioteca y diario de videojuegos: estados, etiquetas, valoración, sesiones, estadísticas, archivado y respaldos JSON. Ejemplos iniciales sin afiliación con los títulos mencionados. Icono y portadas abstractas propios.

Los cambios se guardan únicamente en este navegador. Exporta respaldos para conservarlos o transferirlos. No ingreses información sensible; no hay cuentas, sincronización ni copias automáticas en la nube.

Incluye manifest y caché para uso sin conexión después de una primera carga exitosa. Compatibilidad e instalación dependen del navegador. Cierra todas las pestañas del sitio y vuelve a abrir para activar actualizaciones.

Este repositorio contiene solamente archivos estáticos compilados. El proyecto principal permanece privado. No contiene bibliotecas personales, credenciales ni bases de datos.
